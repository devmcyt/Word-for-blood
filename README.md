# Woba-Race
A simple word racing game to fill a cup of Blood!
This project was made using HTML, CSS, And Javascript.
the HTML and CSS have been entirely handmade, with some debugging with the use of github Copilot.
The Javascript has been made with around 50% help of AI since I didn't want to make the project API based, and therefore i had AI guide me through making the correct functions for a random word picker from a text file, i made the functions i knew how to make, and adjusted them accordingly to the knew functions and constants which were provided by Copilot.
Thank you!
